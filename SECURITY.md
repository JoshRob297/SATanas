# 🛡️ Política de Seguridad

La seguridad de las credenciales y los datos fiscales es una prioridad fundamental en **SATanas**.

## Versiones Soportadas

Actualmente se reciben reportes de seguridad y parches para las siguientes versiones:

| Versión | Soportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en este proyecto, te solicitamos seguir las prácticas de divulgación responsable:

1. **NO** abras un Issue público ni comentes en discusiones abiertas de GitHub.
2. Utiliza la función oficial de **[GitHub Security Advisories](https://github.com/JoshRob297/SATanas/security/advisories/new)** para reportar de forma privada y segura la vulnerabilidad al mantenedor.
3. Si no tienes acceso a los advisories privados, puedes contactar al mantenedor mediante un mensaje privado a través de su perfil de GitHub ([@JoshRob297](https://github.com/JoshRob297)).

### Qué incluir en tu reporte:
- Descripción clara de la vulnerabilidad y su impacto potencial.
- Pasos detallados o código de prueba (Proof of Concept) para reproducir el problema.
- Cualquier mitigación o solución propuesta si la tienes identificada.

Agradecemos enormemente el tiempo y esfuerzo de los investigadores de seguridad en ayudarnos a mantener SATanas seguro.
